## 検出した問題と修正

1. **再現用CSVのID変換**：通常の`read.csv()`が`01`と`1`を統合し、文字列の
   `NA`を欠測に変えていた。実際に282採点行・48人・6評価者が、再実行後には
   232行・47人・5評価者へ変わり、尤度も変化した。ID列を文字型として読み、
   空欄と文字列NAを区別する。元の列名も保持する。
2. **潜在回帰の背景データ**：別CSVのID・空白付き列名・数値風factor水準が
   変換されていた。文字列型を保持してからfactorの水準順序、ordered属性、
   明示的なcontrastを復元する。空白を含むパスでの直接Rscript実行も検査・修正した。
3. **診断設定の脱落**：再現時に`legacy`が`both`へ、FACETS自由度がengineへ、
   ZSTDの変換が既定値へ戻っていた。interactionの選択・件数、PCAの対象と成分数を
   含めて保存する。回帰テストはPCAの成分数と負荷量も照合する。
   古い診断オブジェクトには設定の一部が残っていないため、必要なら診断を再計算して
   から保存する手順をヘルプに記載した。
4. **FACETS互換経路の再実行エラー**：`run_mfrm_facets()`が受け付けない
   `rating_min`/`rating_max`を生成コードから削除し、元のMML engineを引き継ぐ。
5. **重み付き報告の観測数**：重み合計を観測件数として記述していた。
   APA本文・視覚要約は保持された採点行数を使い、重み合計は別に明記する。
   fit summaryの`N`が重み合計を表す従来の計算規約は維持した。
6. **日本語の診断停止**：native encodingのIDがradix sortで失敗していた。
   共通のデータ準備段階でIDをUTF-8へ正規化し、周辺診断などの下流経路を修正した。
7. **図の読みやすさ**：評価者profileの長い名称が左端で切れていたため、文字の
   実測幅から余白を確保し、収まらない場合は広いdeviceまたは表を案内する。
   FACETS-styleの複数行ラベルが重なる場合にも警告を追加した。既定フォントの
   日本語が四角になる問題は、対応フォントを選ぶ手順と保存画像の確認を案内する。

## 判定の点検と限界

「エラーなし」を正しさの代用にしなかった。CSV再実行の不具合は、処理自体が
完了しても人数と推定値が変わることで検出した。反対に、分断設計の拒否や
カテゴリー情報不足の警告は正しい挙動として扱った。レビュー状態のfitから
APAの正式推論可否が勝手に肯定へ変わらないことも検査した。

テスト側の前提も確認した。重み付きsummaryの`N`を行数と仮定した検査、
実際には重複列を作れていなかった検査、混在する非数値得点に必ず停止を期待した
検査は、実データ構造と既存仕様に合わせて修正した。これらを製品の不具合件数に
加えていない。図も実行成功だけで判定せず、保存画像を見て修正した。

今回の結果は、列挙した入力・経路におけるソフトウェアの整合性を裏付ける。
全データでの収束、推定の不偏性、区間被覆率、実データの仮定適合性、研究上の
妥当性を証明するものではない。3シードは動作の変動確認であり、十分な反復数の
統計的性能評価ではない。Windows/Linux、他のRバージョン・フォント、非常に
大きいデータ、全ての高次interaction・anchoring・予測機能の組合せは今回の範囲外。
リポジトリ全体の全テスト実行やCRAN check完了とも区別する。

## 再実行

`development`を作業ディレクトリとし、通常の開発依存パッケージを用いる。
既存のシナリオ生成器とtestthatを再利用し、新しい依存パッケージは追加していない。

```r
pkgload::load_all('.', quiet = TRUE)
source('inst/validation/user-data-stress-0.2.4.R')
qa <- tempfile('mfrmr-user-data-stress-')
run_user_data_stress(file.path(qa, 'scenarios'))

lib <- file.path(qa, 'lib')
dir.create(lib, recursive = TRUE)
system2(file.path(R.home('bin'), 'R'),
        c('CMD', 'INSTALL', paste0('--library=', shQuote(lib)), shQuote(getwd())))
run_user_data_archive_stress(file.path(qa, 'archives'), library = lib)
```

今回の生ログ、別プロセス用スクリプト、分析bundle、PNG：
`/tmp/mfrmr-wide-stress-qa/`。集計は上記のCSVに保存した。
