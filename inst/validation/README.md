# Development validation assets

This directory contains supplementary scripts and historical evidence in the
GitHub source repository; it is excluded from the package source archive. For
package use, see the [README](../../README.md), reference help, and vignettes.

`user-data-replay-0.3.2.R` checks that representative synthetic rating data can
be read, analyzed, and carried through a moved-folder workflow using an
installed package. It checks data and result reproducibility; it is not a
sampling study of parameter recovery, interval coverage, or model performance.

Other files record earlier development versions or research questions. Their
results apply only to the source, data, and conditions recorded with them and
do not validate the current release by themselves. The current test selection
and commands for the full suite are documented in
[CONTRIBUTING](../../CONTRIBUTING.md).
