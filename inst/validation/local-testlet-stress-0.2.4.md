# 人×評定者の局所依存：固定点のストレステスト

2026-09-17。既存の[固定点照合](local-testlet-tam-reference-0.2.4.md)を拡張する。
以下の設計・許容差・追加計算の上限を、ストレス条件の実行前に記録した。

## 問いと事前の設計

同じ答案に対する複数基準の点が強く依存する場合や、極端な得点・欠測がある場合、
前回の積分設定でも目的の尤度と事後分布を計算できるかを調べる。
6人×2評定者×3基準、カテゴリ0/1/2のモデルと固定効果の尺度は前回と同じ。
局所分散は標準化した負荷量で指定し、潜在共分散は単位行列のまま固定する。
母集団パラメータの推定・識別・回復・区間被覆率はこの実験の問いではない。

- 境界と強い依存：v=1e-10,1e-6,.049,.05,.051,1,4,9,16。元の応答表を固定。
- 極端な位置：alpha=-40,-8,8,40（v=.49）。遠い事後分布の切断を調べる。
- カテゴリの偏り：tau1=-8,8。大きな固定効果：beta=(-6,0,6), d=(4,-4)。
- 疎な観測：各ペア1基準、評定者間に共通受検者なし、R1の全欠測、
  P6の全欠測、全セル欠測。尤度が存在することと未知効果を推定できることを分ける。
- 応答の端：全セル0、全セル2、評定者ごとに0/2へ二極化。
  応答やカテゴリを補うダミー行を入れず、外部実装のエラーもそのまま記録する。

対数尤度と事後平均・SDの絶対差は1e-6、微分は1e-5を許容差とする。
独立参照は条件付きに分解したGauss–Hermite積分81/121点から始め、参照自体が
収束しなければ181/241点まで追加する。隣り合う段階で尤度・モーメント1e-7、
微分1e-6以内になることを比較の前提とする。未解決ならTAMの誤りと判定しない。

TAMは前回と同じ各次元[-7,7]・41点から始める。不一致の条件だけ[-7,7]・81点、
さらに[-14,14]・81点と必要時121点へ進む。全欠測等の入力エラーは細分化で再試行
しない。初回の不一致・警告・エラーを保持する。有限の範囲拡大で解決しなければ
未解決として報告し、許容差を緩めない。

比較参照にも尾部の問題があり得る。元の固有ベクトル由来のGH重みは高次数で
一部が数値的に0になることを事前点検で確認した。ストレス用には同じ固有値を
用い、正規直交Hermite多項式の漸化式から重みを計算する。積分は対数尺度で行う。
正規分布の既知モーメント・指数傾斜の積分、および前回保存済みの3固定点と照合する。
前回のコードと原記録は変更しない。

微分の追加照合は事前指定した境界(v=1e-10)、強依存(v=9)、位置(alpha=8)、
疎な観測（各ペア1基準）の4条件で行う。参照とTAMの尤度・モーメントが収束した
最後の格子を使い、全6座標を刻み1e-4/5e-5の中心差分と比較する。

## 結果

**元の41点・±7という設定を全条件へ流用できない。** 第一段階の24条件は、
元の設定で一致15、細分化・範囲拡大後に一致5、範囲拡大の上限でも未解決2、
TAMの入力処理エラー2だった。独立参照は24条件すべてで所定の収束基準を満たした。
後述の追加確認で範囲不足の2条件も一致し、最終的には22条件で数値的な対応を
確認した。全欠測と全最低点の2条件はTAM経路で扱えないまま残す。

| v=16 | 1.44e-5 | 4.86e-5 | ±7・81点。独立参照も241点まで必要 |
| alpha=-8 / 8 | .0855 / .0848 | .1023 / .1020 | ±14・81点 |
| tau1=-8 | .00303 | .00696 | ±14・81点 |
| 大きな基準・評定者効果 | 1.93e-6 | 1.26e-5 | ±14・81点 |
| alpha=-40 / 40 | 15.11 / 14.56 | 5.065 / 5.065 | 一次試験では未解決。追加の±20・121点で一致 |

v=1e-10から1e-6、.05の前後、v=1,4,9は元の設定で一致した。
各ペア1基準、分断配置、評定者全体の欠測、1人全体の欠測、全最高点、
評定者ごとの0/2への二極化も元の設定で一致した。これらの疎な配置で尤度を
評価できるのは母集団パラメータを固定しているためであり、共同推定の識別を
確認したことにはならない。

事前指定4条件の微分は、6座標×2刻みの中心差分で比較し、24座標すべて許容差内。
最大差はv=9で6.79e-7（許容差1e-5）だった。参照の資格確認11項目もすべて通過し、
前回の保存済み3固定点への差は最大6.14e-14。全最低点の独立参照対数尤度は
-24.30425、全欠測では約0となり、指定したモデルの固定点積分自体は定義できる。

TAM 4.3.25の保存済み関数本体では、`maxK <- max(resp, na.rm=TRUE)+1`と
観測値からカテゴリ数を定めていた。全最低点では1カテゴリと解釈する処理と
指定した3カテゴリの設計が整合せず、全欠測では最大値を取得できない。
ダミー応答でカテゴリを補う変更は行っていない。将来のラッパーには、宣言した
カテゴリ集合を保てる経路と、この経路で扱えない入力を明示する契約が必要である。

成功した数値計算だけを抜き出して「全条件成功」とは集計しない。
一次試験の不一致とエラーは[条件別結果](local-testlet-stress-0.2.4-cases.csv)と
[全39回の格子評価](local-testlet-stress-0.2.4-attempts.csv)へ残した。

## 第一段階の不一致に対する追加確認の設計

第一段階でalpha=-40の独立参照が収束し、P5の事後能力平均が約12、SDが約1と
分かった。TAMは±14でも許容差に届かなかった。これは積分範囲による切断という
仮説に対応する。初回結果を保持したまま、alpha=-40と対称側の40に限って、
各次元[-20,20]・121点を1回ずつ評価する。この追加確認は第一段階の結果を見た後の
診断であり、事前24条件の集計へ混ぜない。許容差は変更しない。

極端な位置では、全最高点（alpha=-40）または全最低点（alpha=40）の人の尤度が
正規分布の指数傾斜へ近づく。6観測から能力平均はそれぞれ約12/-12、能力SDは約1、
各局所効果の平均は約2.94/-2.94、SDは約.7になる。この近似への差も1e-6で確認する。
元の参照計算もこの2条件のみ比較し、尾部重みの変更が必要だったかを記録する。

## 追加確認の結果と開発上の判断

±20・121点では両条件とも一致した。対数尤度差は最大6.83e-13、事後平均/SD差は
最大4.03e-12。独立参照は指数傾斜による近似にも最大3.25e-10で一致した。
点数を41から81へ増やしても±7の切断は改善せず、±14でも最大約.0476の
モーメント差が残ったことと合わせ、今回の不一致は積分範囲不足で説明できる。

一方、元の独立参照をこの極端な2条件にそのまま使うと、対数尤度は約.3469、
平均/SDは最大約.4891ずれた。前回の通常条件への照合が成功していたことだけでは、
比較参照の尾部精度を保証できなかった。今回、TAMと参照の双方を点検した意味が
ここにある。旧コードは前回結果の再現用として保存し、今後この範囲で使う独立参照は
尾部重みを保持する今回の計算を用いる。

未知分散を推定する経路へ進む前に、**積分点の密度と積分範囲を別々に点検し、
基準を満たさない固定点を最適化の成功と混同しないこと**が必要と分かった。
今回の±20をすべてのモデルに対する普遍的な既定値とする根拠はない。評定者が増える
場合の計算量、未知分散の境界推定、初期値感度、回復・被覆、共通受検者の少ない
配置での性能は未確認。受検者間で共有するランダム評定者効果も別の課題として残る。
