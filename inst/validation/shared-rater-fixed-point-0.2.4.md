# 共有ランダム評定者：小例の固定点尤度

2026-09-17。系列Rの最初の数値実装。以下の範囲と許容値は実行前に記載した。

## 問いと計算範囲

同じ評定者が複数人を採点する場合、評定者の厳しさはその全員に共有される。
人ごとに独立な評定者効果として積分すると尤度が変わる。この違いを保持した
R実装が、既に保存したPythonの小例と一致するかを確かめる。

`eta_prj = alpha + theta_p - beta_j - u_r`、thetaは独立な標準正規、
uは評定者ごとに独立な平均0・分散v_Rの正規変数とする。
3カテゴリの隣接ロジットは`eta_prj - tau_k`で、`tau=(-.6,.6)`を小例に使う。
各人についてthetaを積分した条件付き尤度の**積を作ってから**共有uを積分する。
uの標本内中心化は行わない。v_R=0ではuを厳密に0へ固定する。

[実装](shared-rater-fixed-point-0.2.4.R)は既存の確率関数と標準正規積分則を再利用し、
対数上で計算する。応答配列の軸はperson/rater/criterionで、NAは未観測を表す。
戻り値は対数尤度と指定した積分次数のみ。次数を自動調整したり、収束を保証する
戻り値ではない。較正値・分散の推定、勾配、事後採点、公開APIは含まない。

参照用の全格子積分は評定者1～2人・次数3～121に制限する。初回確認は2人×2評定者
×2基準で、alpha=0、beta=(-.3,.3)、能力分散1、評定者SD=.7、次数41/81とする。
固定能力を渡す引数は既存の一評定者の適応積分例との照合用であり、未知の能力へ
点推定を代入する推測法の提案ではない。全体の数値安定性や12評定者への実用性は
この小例の一致から主張しない。

## 一度実行する照合

参照入力は[保存JSON](../../../research-notes/2026-09-17-random-effects-rating-design/model-sharing-check.json)
と[Pythonソース](../../../research-notes/2026-09-17-random-effects-rating-design/model-sharing-check.py)。
Pythonの再計算は行わず、既存の結果を読む。JSONとRの配列順は明示的に変換し、
両受検者の応答を照合する。

| 確認 | 基準 |
|---|---|
| Pythonの41/81点との対数尤度、R内の41/81点差 | 絶対差≤1e-7 |
| v_R=0の保存対数尤度 | 絶対差≤1e-7 |
| v_R=0と直接の能力1次元積分 | 絶対差≤1e-12 |
| 評定者または受検者のラベル交換 | 対数尤度の絶対差≤1e-12 |
| 人ごとにuを積分し直した値と、共有モデルとの差 | 保存された対数値／差との絶対差≤1e-7 |
| 固定能力・一評定者の独立な適応積分結果 | 対数尤度の絶対差≤1e-7 |
| 全未観測の尤度1、未観測評定者の積分除去 | 対数尤度の絶対差≤1e-12 |
| 不正カテゴリ、負の分散、3評定者以上 | 計算を拒否 |

```sh
Rscript -e 'options(warn=2); source("inst/validation/shared-rater-fixed-point-0.2.4.R"); run_shared_rater_fixed_point()'
```

値と照合表を本ディレクトリのCSVへ、入力・ソースハッシュ・セッション・全照合結果を
`validation-results/shared-rater-fixed-point-20260917/evidence.rds`へ保存する。
系列L本試験の入力・数値ソース・集計ソースを変更せず、新しいシミュレーションや
全パッケージテストはこの固定点実装の確認に含めない。

## 結果

警告をエラー扱いにした1回の実行で、[15項目](shared-rater-fixed-point-0.2.4-checks.csv)
すべてが基準を満たした。[計算値](shared-rater-fixed-point-0.2.4-values.csv)では、
共有モデルの対数尤度は41/81点とも約−7.61845115123505、尤度は約0.00049130219491449。
Python保存値との差は41点で1.78e-15、81点で7.11e-15、Rの次数間差は1.78e-15だった。

人ごとに評定者効果を積分し直す計算の対数尤度は約−8.04369267965427で、共有モデルとの
差0.425241528419216を保存値どおり保持した。この違いは当該応答の尤度の違いであり、
モデルの優劣や推定・予測性能を示す値ではない。

ゼロ分散と直接の1次元積分、評定者・受検者のラベル交換はこの実行で差0だった。
一評定者・固定能力の例はPythonの独立な適応積分とも対数尤度差0だった。
未観測の処理と対象外入力の拒否も確認した。全照合が同じ小例の限定された確認であり、
推定器の識別、一般的な積分精度、能力区間の妥当性の確認とは区別する。

次の課題は、この小例の共有uの事後重みを使って能力の平均・共分散と能力差の分散を
計算し、全分散・全共分散の関係と次数間の一致を確認すること。それを経て、較正値を
推定する際の識別・勾配・最適化を別に扱う。評定設計Dの性能比較はまだ開始していない。

その後、可視化の依頼を受け、[共同事後分布のPython参照計算と図](shared-rater-posterior-visual-0.2.4.md)
を作成した。同じ小例について積分順序を変えたモーメント照合等19項目を通過した。
共分散を保持した能力差の標準偏差を図示した段階であり、このR尤度関数へ事後採点を
追加したり、差の区間・被覆を検証したわけではない。
