# 人×評定者の局所依存：TAMとの固定点照合

2026-09-17。研究系列Lの最初の数値照合。小例の51確認項目はすべて通過した。
これは指定したパラメータでの計算の対応であり、分散推定・回復・被覆率の検証、
新しい公開推定器の実装、リリース承認ではない。

## 問いと調べ方

同じ評定者が一つの答案に付ける複数基準の点は、答案全体への印象を共有し得る。
その依存を扱うモデルを外部実装へ渡す際に、意味の違う効果や制約へ変換すると、
計算が正常終了しても目的のモデルを推定したことにならない。

今回の問いは、**固定された基準難度・評定者厳しさを持つRSMに、人×評定者の
独立な偏差を加えたモデルを、TAMの設計行列へ正確に対応づけられるか**である。
推定の成否と式の対応を分けるため、すべての構造・母集団パラメータを固定した。
同じデータとパラメータについて、TAMの公開関数による尤度と、独立に書いた
基準間・評定者間の積分および解析的微分を比較した。

## モデル・尺度・データ

隣接カテゴリモデルを用いる。

`log{P(Y_pjr=k)/P(Y_pjr=k−1)} = alpha + theta_p − beta_j − d_r + gamma_pr − tau_k`

- `theta_p ~ N(0,1)`、`gamma_pr ~ N(0,v)`。すべて独立。
- `gamma_pr`を共有するのは、同じ人×評定者の3基準だけ。同じ評定者でも人が
  違えば別の乱数になる。受検者間で共有するランダム評定者モデルではない。
- `alpha=.2`、基準効果`beta=(-.4,.1,.3)`、固定評定者効果`d=(-.25,.25)`、
  閾値`tau=(-.6,.6)`。beta・d・tauはそれぞれ和0。重み1。
- 6人×2評定者×3基準、カテゴリ0/1/2。全最低点・全最高点の人を含み、
  P6×R1の3基準を欠測とした。観測33個。乱数による生成ではなく固定小例。
- 同じ応答表で`v=0,.01,.49`を評価。3つの独立データセットではない。

TAMの1列を「評定者×基準」、1行を人に対応づける。局所効果を標準化し、
`gamma_pr=sqrt(v)*z_pr`、`(theta_p,z_p1,z_p2) ~ N(0,I)`と表す。
カテゴリkの負荷量は、一般能力にk、担当評定者の局所次元に`k*sqrt(v)`。
固定効果の自由座標は`(alpha,beta1,beta2,d1,tau1)`で、カテゴリkの設計行は
`(k, −k*C_j1, −k*C_j2, −k*D_r, −1{k=1})`とする。
`C=((1,0),(0,1),(-1,-1))`、`D=(1,-1)`である。

`tam.mml(A=...,B=...)`へ渡し、平均0、共分散I、全xiを固定。
`est.variance=FALSE`も明示して単位共分散を保持する。`v=0`では局所次元を
取り除く。mfrmrの通常RSMへの写像は、ステップを`tau_k−alpha`とする。
固定効果の設計行列の階数5は確認したが、これは未知分散の識別や有限MLEの
存在を証明する検査ではない。

## 外部実装をそのまま使えない条件

確認対象はインストール済みTAM 4.3.25。
[公式ドキュメント](https://alexanderrobitzsch.github.io/TAM/reference/tam.mml.html)
の設計行列・共分散指定を、ローカルの関数本体と照合した。
`tam.mml.mfr()`には共分散コールバックがないため、今回は明示したA/Bを
`tam.mml()`へ渡している。

さらに、[TAMの多次元の密度計算](https://github.com/cran/TAM/blob/master/R/tam_stud_prior.R)
は`tam_ginv(...,eps=.05)`を呼ぶ。ローカルの関数では、.05未満の特異値を
.05へ置換し、元のトレースへ再調整する。したがって、局所効果を未標準化のまま
`diag(1,.01,.01)`で固定すると、密度は次の共分散から計算される。

`diag(1,.05,.05) * (1.02/1.1) = diag(.9272727273,.04636363636,.04636363636)`

原点での密度は、宣言した共分散なら6.34936359、実際のTAMの計算では
1.42216165となった。他の2点でも補正後の密度と一致した。これは小さい分散を
含む多次元モデルでの具体的な反例であり、TAM全体が使えないという意味ではない。
今回の標準化表現は共分散Iを使うため、この補正を受けずに同じモデルを表せる。

開発途中の最初の呼び出しでは、固定共分散にもMステップで`1e-10`が加わり、
厳密な同一性確認が停止した。関数本体から原因を確認し、今回の単位共分散に
適した`est.variance=FALSE`を明示した。尤度・微分の許容差は変更していない。
未知のvを推定する際に同じ指定がそのまま使える、という結論ではない。

## 確認結果

TAMでは各次元を[-7,7]の41等間隔点で積分。独立参照では標準正規分布の
Gauss–Hermite 61点と81点を用い、人の能力に条件づけて2つの局所積分を分けた。
基準内の応答確率と積分順序を独立に記述し、参照計算にmfrmr/TAMの尤度を使わない。
TAMの生のdevianceでは格子幅の積も含めて比較した。

| 局所分散v | 参照対数尤度（概数） | TAMとの対数尤度差 | 事後平均・SDの最大差 |
| ---: | ---: | ---: | ---: |
| 0 | -32.71402 | 2.93e-11 | 4.50e-10 |
| .01 | -32.67423 | 3.70e-11 | 4.47e-10 |
| .49 | -31.66594 | 3.00e-11 | 3.50e-10 |

構造5座標と、正のvでのlog(v)について、解析的微分をTAM公開関数の中心差分
（刻み1e-4と5e-5）と比較した。小さい刻みでの最大差は8.77e-10。
nodeごとのカテゴリ確率の最大差は5.56e-16だった。
評定者のラベル・応答列・固定効果を同時に交換した場合と、局所次元の基底の符号を
反転した場合も対応した。P6×R1の局所効果は観測されていないため、事後平均0・
事後SD=sqrt(v)を保持した。ゼロ局所分散での通常RSMの確率も一致した。

許容差は対数尤度・事後平均/SDで1e-6、微分で1e-5、node確率で1e-12。
尺度変換の確認と統計的性能の基準は区別する。対数尤度が大きい分散を採用する
モデル選択は実施していない。
