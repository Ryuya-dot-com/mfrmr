# Documentation for versions 0.3.1 and earlier

These articles, templates, and examples use earlier mfrmr interfaces. Use them
with the version described in each document. For 0.3.2, see the
[current assessment guide](../vignettes/articles/mfrmr-assessment.Rmd) and the
[documentation website](https://ryuya-dot-com.github.io/mfrmr/).

- [Articles](articles) retain worked examples from earlier versions.
- [Report templates](templates), the [cheatsheet](cheatsheet), and the
  [FACETS crosswalk](reference/FACETS_manual_mapping.md) record the earlier
  reporting and plotting interfaces.
